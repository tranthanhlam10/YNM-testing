# Tools

Các tool và skill độc lập được tách khỏi tài liệu để source code, rule và test nằm cùng một chỗ.

- `generate-jira-bugs-review-vi/`: engine tạo/preview Jira bug và bộ test đi kèm.
- `logging-bugs-to-jira/`: skill mô tả workflow log bug lên Jira.
- `logging-bugs-to-jira_new.skill`: gói skill đã đóng gói.
