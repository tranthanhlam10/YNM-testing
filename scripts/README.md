# Scripts

- `rabbitmq/`: đọc, lọc, push và purge message.
- `verification/`: đối chiếu dữ liệu loader, post, comment, reply và mention.
- `helpers/`: script hỗ trợ dữ liệu, proxy, token, URL và image.
- `utilities/`: tiện ích ID, regex, hash và shard.
- `solr/`: truy vấn hoặc xuất dữ liệu từ Solr.

Đây chủ yếu là script chạy trực tiếp, chưa phải thư viện dùng chung. Kiểm tra constant cấu hình và đường dẫn input trong từng file trước khi chạy.
