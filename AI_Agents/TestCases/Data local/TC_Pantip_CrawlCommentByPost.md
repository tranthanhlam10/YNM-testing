## TỔNG QUAN LUỒNG

```
Solr (pantip_posts)
    → [Loader] Load post source, lock Redis, push → queue crawling_sources
    → [Builder] Consume crawling_sources, build API request → push → queue crawling_requests
    → [Crawler] Consume crawling_requests, dùng proxy, gọi Pantip Web API → push → crawled_sources
    → [Resolver] Consume crawled_sources, map data → Mentions / Identities / next_page
    → [Data Pusher] Push mentions → Solr mentions | identities → Solr/Redis | update source
```

**Queue liên quan:**
- `cl.pt.comments_no_cookie_crawling_sources`
- `cl.pt.comments_no_cookie_crawling_sources_next_pages`  
- `cl.pt.comments_no_cookie_crawling_requests`

**Mongo Collection:** `pantip_posts`  
**Redis Key:** `PTCommentNoCookieCrawlingLoader`  
**MySQL Key:** `PT_COMMENT_NO_COOKIE_CRAWLING_LOADER`  
**Crawler Proxy Type:** `PT_COMMENT_NO_COOKIE_CRAWLER`
